MULTIPLE INHERITANCE DENGAN MIXIN, POLIMORFISME, DAN ABSTRAKSI

Dalam pemrograman berorientasi objek, terdapat beberapa konsep penting seperti multiple inheritance dengan mixin, polimorfisme, dan abstraksi yang saling berkaitan.

 

1. Mixin : Cara menambahkan kemampuan/fungsi ke dalam class tanpa perlu menurunkan class induk, supaya satu class bisa punya banyak sifat sekaligus.

2. Polimorfisme : Kemampuan satu bentuk data untuk memiliki banyak perilaku berbeda, membuat kode jadi lebih fleksibel dan mudah diatur.

3. Abstraksi : Teknik menyembunyikan detail rumit di balik layar dan hanya menampilkan fungsi utamanya saja, supaya program lebih simpel dan mudah dipakai.

 

Ketiga konsep ini membantu dalam membuat program yang lebih terstruktur, mudah dikembangkan, dan mudah dipelihara.

STUDI KASUS BURUNG DAN BEBEK

Burung merupakan class induk, sedangkan Bebek class turunan. Bebek mewarisi sifat dari Burung meskipun mereka sejenis, perilaku Bebek bisa berbeda.

// Nama   : Alicia Putri Lestari
// Nim    : 251410011
// Kelas  : SI2A

mixin CanFly {
  void fly() {
    print('Can fly!');
  }
}

mixin CanSwim {
  void swim() {
    print('Can swim!');
  }
}

class Bird with CanFly {}
class Duck extends Bird with CanSwim {}

void main() {
  print("=== MIXIN BASIC ===");
  Bird bird = Bird();
  bird.fly();
  Duck duck = Duck();
  duck.fly();
  duck.swim();
}

STUDI KASUS MIXIN DENGAN STATE

Teknik menambahkan fitur sekaligus menyimpan data ke dalam class tanpa perlu pewarisan langsung. Dengan ini, class bisa punya kemampuan tambahan beserta datanya sendiri secara mandiri.

      _isSwimming = false;

PENGANTAR CLASS MODIFIERS

Class modifiers adalah kata kunci khusus di Dart yang berfungsi sebagai pengatur dan pengendali. Ia menentukan aturan main sebuah class, mulai dari cara penggunaannya, batasan pewarisan, hingga pembatasan akses agar tidak disalahgunakan. Dengan fitur ini, pengembang punya kuasa penuh untuk mengatur perilaku class agar bekerja persis seperti yang direncanakan.

 

Setiap jenis modifier punya tugas spesial, mulai dari membatasi siapa yang boleh menurunkan class, melindungi class agar tidak berubah, sampai memastikan implementasi dilakukan dengan benar. Semua ini bertujuan agar struktur program tetap aman, rapi, dan terorganisir.

 

Kenapa Menggunakan Class Modifiers

🌸 Mengontrol secara detail bagaimana class dipakai dan diturunkan

🌸 Mencegah penggunaan class secara sembarangan atau salah cara

🌸 Menjaga agar struktur dan logika program tetap konsisten dan aman

🌸 Memudahkan perawatan serta pengembangan kode dalam jumlah besar

SEALED CLASS

Sealed class adalah class yang membatasi pewarisan hanya dalam satu file, agar pembuatan subclass lebih terkontrol dan semua kondisi program bisa ditangani dengan pasti.

// Nama   : Alicia Putri Lestari
// Nim    : 251410011
// Kelas  : SI2A

sealed class ApiResponse {}

class Success extends ApiResponse {
  final String message;
  Success(this.message);
}

class Error extends ApiResponse {
  final String errorMessage;
  Error(this.errorMessage);
}

void handleResponse(ApiResponse response) {
  switch (response) {
    case Success(message: final msg):
      print("✅ Sukses: $msg");
    case Error(errorMessage: final err):
      print("❌ Error: $err");
  }
}

void main() {
  print("=== CONTOH SEALED CLASS ===");
  handleResponse(Success("Data berhasil dimuat!"));
  handleResponse(Error("Koneksi internet bermasalah"));
}

KEUNTUNGAN SEALED CLASS

🌸 Pembuatan subclass lebih terkontrol, hanya boleh di satu file

🌸 Keamanan lebih terjamin karena tidak sembarangan bisa mewarisi

🌸 Memudahkan penanganan kondisi dengan pattern matching

🌸 Mencegah adanya kondisi atau kasus yang tidak tertangani

BASE CLASS

Class yang boleh diturunkan (di-extends), tapi tidak boleh di-implements dan pembuatannya dibatasi hanya dalam satu library yang sama.

// Nama  : Alicia Putri Lestari
// Kelas : SI2A
// Nim   : 251410011

base class Hewan {
  void bersuara() {
    print("Suara hewan");
  }
}

base class Kucing extends Hewan {
  @override
  void bersuara() {
    print("Meong! 🐱");
  }
}

base class Anjing extends Hewan {
  @override
  void bersuara() {
    print("Guk guk! 🐶");
  }
}

void main() {
  print("=== CONTOH BASE CLASS ===");
  var kucing = Kucing();
  kucing.bersuara();
  var anjing = Anjing();
  anjing.bersuara();
}

KAPAN MENGGUNAKAN BASE CLASS

Digunakan saat ingin membatasi pewarisan agar hanya boleh pakai extends dan tetap dalam kendali penuh. Ini menjaga struktur program agar tidak dipakai sembarangan, serta memastikan class anak mengikuti aturan yang sudah ditetapkan.

 

Kapan dipakai:

🌸 Saat ingin membatasi pewarisan hanya dengan extends

🌸 Saat ingin menjaga struktur class tetap rapi dan konsisten

🌸 Saat ingin mencegah penyalahgunaan kata kunci implements

FINAL CLASS

Final class adalah class yang terkunci rapat, tidak boleh diturunkan atau diubah oleh class lain sama sekali.

 

Kegunaan:

🌸 Melindungi struktur agar tidak diwariskan

🌸 Menjaga kode agar tetap asli dan tidak berubah

🌸 Meningkatkan keamanan dan kestabilan program

// Nama  : Alicia Putri Lestari
// Kelas : SI2A
// Nim   : 251410011

final class Settings {
  final String theme;
  final int fontSize;
  Settings({required this.theme, required this.fontSize});
  void showSettings() {
    print("Theme: $theme, Font Size: $fontSize");
  }
}

void main() {
  var setting = Settings(theme: "Dark", fontSize: 14);
  setting.showSettings();
}

PERBANDINGAN CLASS MODIFIERS

🌸 abstract : Tidak bisa dijadikan objek, hanya sebagai kerangka dasar.

🌸 base : Boleh diturunkan, tapi hanya dalam satu library yang sama.

🌸 interface : Berfungsi sebagai aturan yang wajib diikuti/diimplementasikan.

🌸 final : Terkunci total, tidak boleh diturunkan atau diubah sama sekali.

🌸 sealed : Turunan terbatas hanya boleh ada di dalam satu file yang sama.

PRAKTIK 1 SEALED CLASS DENGAN PATTERN MATCHING

Memastikan kita tahu semua jenis turunan yang ada, sehingga setiap kondisi bisa dicek dan ditangani dengan tepat sesuai jenisnya. Ini membuat kode jadi lebih aman dan lengkap, karena tidak ada kasus yang terlewat.

// Nama  : Alicia Putri Lestari
// Kelas : SI2A
// Nim   : 251410011

sealed class Status {}

class Loading extends Status {}
class Loaded extends Status {
  final String data;
  Loaded(this.data);
}
class Failed extends Status {
  final String error;
  Failed(this.error);
}

void handleStatus(Status status) {
  switch (status) {
    case Loading():
      print('Loading...');
    case Loaded(:final data):
      print('Data: $data');
    case Failed(:final error):
      print('Error: $error');
  }
}

void main() {
  print("=== SEALED PATTERN ===");
  handleStatus(Loading());
  handleStatus(Loaded("Data berhasil"));
  handleStatus(Failed("Terjadi kesalahan"));
}

SISTEM STATE MANAGEMENT

Cara mengatur keadaan aplikasi (seperti loading, success, error) agar teratur. Dengan sealed class, setiap kondisi bisa dibuat dengan sangat jelas.

 

Fitur: Mengatur kondisi aplikasi, mengendalikan alur kerja program

 

Kenapa Penggunaan: Struktur jadi lebih rapi dan jelas, mencegah error yang tidak tertangani

 

Batasan: Bisa jadi rumit kalau jenis kondisinya terlalu banyak

// Nama  : Alicia Putri Lestari
// Kelas : SI2A
// Nim   : 251410011

sealed class AppState {}

class LoadingState extends AppState {}
class SuccessState extends AppState {
  final List items;
  SuccessState(this.items);
}
class ErrorState extends AppState {
  final String message;
  ErrorState(this.message);
}

void updateUI(AppState state) {
  switch (state) {
    case LoadingState():
      print('Loading...');
    case SuccessState(:final items):
      print('Success: $items');
    case ErrorState(:final message):
      print('Error: $message');
  }
}

void main() {
  print("=== APP STATE ===");
  updateUI(LoadingState());
  updateUI(SuccessState(["A", "B"]));
  updateUI(ErrorState("Gagal"));
}

RINGKASAN:

🌸 Sealed = Mengatur hierarki & mendukung pattern matching

BONUS BASE CLASS REPOSITORY

Membuat class yang hanya boleh dijadikan induk pakai extends, dan dilarang keras dipakai pakai implements.

 

Fitur Base Class pada Repository: Pewarisan wajib pakai extends, tidak bisa dijadikan kontrak di luar, bentuk fungsi tetap terjaga.

 

Kenapa menggunakan base: Pola CRUD jadi standar, mencegah cara pakai yang salah, penggunaan lebih aman & teratur.

 

Batasan: Tidak boleh pakai kata kunci implements

// Nama  : Alicia Putri Lestari
// Kelas : SI2A
// Nim   : 251410011

base class Repository {
  final List _data = [];
  void create(T item) {
    _data.add(item);
    print("Data ditambahkan: $item");
  }
  void read() {
    print("Isi data:");
    for (var item in _data) print("- $item");
  }
  void update(int index, T newItem) {
    if (index >= 0 && index < _data.length) {
      _data[index] = newItem;
      print("Data diupdate di index $index");
    }
  }
  void delete(int index) {
    if (index >= 0 && index < _data.length) {
      print("Data dihapus: ${_data[index]}");
      _data.removeAt(index);
    }
  }
}

base class UserRepository extends Repository {}

void main() {
  var repo = UserRepository();
  repo.create("Alicia");
  repo.create("Budi");
  repo.create("Cici");
  print("\n--- Setelah Ditambah ---");
  repo.read();
  repo.update(1, "Budi Update");
  print("\n--- Setelah Diubah ---");
  repo.read();
  repo.delete(0);
  print("\n--- Setelah Dihapus ---");
  repo.read();
}

BONUS FINAL CLASS MATHUTILS

MathUtils dibuat menggunakan final class karena isinya hanya fungsi bantuan (utilities) yang sifatnya umum dan tidak perlu diwariskan ke class lain.

 

Fitur Final Class pada MathUtils: Tidak bisa di-extend, tidak bisa di-implement, cocok untuk method static.

 

Kenapa Menggunakan final? Mencegah class diwariskan, menjaga fungsi tetap sederhana, cepat, aman, menghindari perubahan perilaku.

 

Batasan: Tidak bisa diwariskan sama sekali.

// Nama  : Alicia Putri Lestari
// Kelas : SI2A
// Nim   : 251410011

final class MathUtils {
  static int add(int a, int b) => a + b;
  static int subtract(int a, int b) => a - b;
  static int multiply(int a, int b) => a * b;
  static double divide(int a, int b) => a / b;
}

void main() {
  print("Hasil Penjumlahan: ${MathUtils.add(10, 5)}");
  print("Hasil Pengurangan: ${MathUtils.subtract(10, 5)}");
  print("Hasil Perkalian: ${MathUtils.multiply(10, 5)}");
  print("Hasil Pembagian: ${MathUtils.divide(10, 5)}");
}
