Rangkuman Materi Generic

    Generic : konsep untuk membuat kode yang bisa digunakan dengan berbagai tipe data secara aman.

    Manfaat : meningkatkan keamanan tipe, mengurangi error, dan memudahkan penggunaan ulang kode.

    Sintaks : menggunakan <T> pada class atau fungsi untuk menentukan tipe data.

    Multiple parameter : dapat menggunakan lebih dari satu tipe, seperti <K, V>.

    Batasan tipe : membatasi tipe tertentu dengan extends.

    Type inference : Dart dapat menebak tipe secara otomatis.

    Perbandingan : lebih aman dibanding dynamic karena dicek saat compile.

    Contoh : List<T>, Map<K, V>, dan class generic lainnya.

🌸 Apa itu Generic?

Generic adalah fitur yang memungkinkan class atau fungsi digunakan untuk berbagai tipe data dengan tetap menjaga keamanan tipe. <T>.

Manfaat:

  • Menjamin tipe data sesuai (type-safe)
  • Mengurangi kesalahan saat program berjalan
  • Membuat kode bisa digunakan kembali (reusable)
  • Tidak perlu casting manual

🌸 Masalah Tanpa Generic (dynamic)

Class ini bisa menyimpan semua tipe data karena menggunakan dynamic, tetapi tidak aman karena tipe tidak dicek saat compile (bisa error saat runtime).

Sukses

Program berjalan dengan baik karena tipe data yang digunakan sudah sesuai, sehingga tidak terjadi kesalahan saat dijalankan.

🌸 Solusi dengan Generic <T>

Menggunakan generic <T> agar tipe data ditentukan sejak awal, sehingga lebih aman (type-safe) dan menghindari error.

Sukses

Program berjalan dengan baik karena tipe data sudah ditentukan sejak awal, sehingga lebih aman (type-safe) dan tidak terjadi error.


// Nama : Alicia Putri Lestari
// Nim  : 251410011
// Kelas: SI2A

class Wrapper<T> {
  T value;

  Wrapper(this.value);
}

void main() {
  var numData = Wrapper<double>(3.14); // T = double
  var textData = Wrapper<String>("Dart"); // T = String

  double result = numData.value; // aman
  print(result);
  print(textData.value);
}

Eror

Program mengalami kesalahan karena tipe data tidak sesuai dengan yang ditentukan sejak awal, sehingga tidak aman (tidak type-safe) dan menyebabkan error.

🌸 Sintaks Generic (Class & Fungsi)

Generic (<T>) digunakan untuk membuat class dan fungsi yang dapat bekerja dengan berbagai tipe data, sehingga lebih fleksibel dan aman (type-safe).


// Nama  : Alicia Putri Lestari
// Nim   : 251410011
// Kelas : SI2A

class Box<T> {
  T data;

  Box(this.data);

  T getData() {
    return data;
  }
}

// Fungsi generic
T showData<T>(T value) {
  return value;
}

void main() {
  // Class generic
  var intBox = Box<int>(25);
  var stringBox = Box<String>("Dart");

  print(intBox.getData());   // Output: 25
  print(stringBox.getData()); // Output: Dart

  // Fungsi generic
  print(showData<int>(100));      // Output: 100
  print(showData<String>("Halo")); // Output: Halo
}

🌸 Contoh kelas Box <T>

Box<T> adalah class generic yang bisa menyimpan berbagai tipe data dengan aman karena tipe ditentukan sejak awal.

  desimal.display();
}

🌸 Multiple Type Parameter: Pair<K,V>

Pair<K, V> adalah generic dengan dua tipe data, dimana K sebagai key dan V sebagai value, sehingga bisa menyimpan dua data dengan tipe berbeda secara aman dan fleksibel.


// Nama  : Alicia Putri Lestari
// Nim   : 251410011
// Kelas : SI2A

class DataPair<K, V> {
  K first;
  V second;

  DataPair(this.first, this.second);

  void show() {
    print('First: $first, Second: $second');
  }
}

void main() {
  // String dan int
  var data1 = DataPair<String, int>('score', 100);
  data1.show(); // Output: First: score, Second: 100

  // String dan String
  var data2 = DataPair<String, String>('city', 'Jakarta');
  data2.show(); // Output: First: city, Second: Jakarta

  // int dan double
  var data3 = DataPair<int, double>(5, 9.5);
  data3.show(); // Output: First: 5, Second: 9.5
}

🌸 Generic dengan extends

Generic dengan extends digunakan untuk membatasi tipe data, sehingga hanya tipe tertentu (misalnya num) yang boleh digunakan dan mencegah kesalahan.

Sukses

Sukses karena int dan double termasuk turunan dari num.

//Nim   : 251410011
//Kelas : SI2A

  T nilai;

  DataAngka(this.nilai);

  T getNilai() {
    return nilai;
  }
}

void main() {
  var a = DataAngka<int>(5);
  print(a.getNilai()); // Output: 5

  var b = DataAngka<double>(2.5);
  print(b.getNilai()); // Output: 2.5

🌸 Type Inference (Inferensi Tipe)

Type inference adalah kemampuan Dart untuk menentukan tipe data secara otomatis dari nilai yang diberikan, sehingga kita tidak perlu menuliskan tipe generic secara manual.

// Nama : Alicia Putri Lestari
// Nim  : 251410011
// Kelas: SI2A

// Fungsi generic
T echo<T>(T input) {
  return input;
}

void main() {
  // Dart otomatis menebak tipe int
  var angka = echo(50);
  print(angka.runtimeType); // Output: int

  // Dart otomatis menebak tipe String
  var teks = echo("Halo Dart");
  print(teks.runtimeType); // Output: String

  // Dart otomatis menebak tipe double
  var desimal = echo(2.5);
  print(desimal.runtimeType); // Output: double
}

Pembatasan tipe dan manfaatnya

Lebih aman: mengurangi kesalahan karena tipe sudah dibatasi

Lebih terkontrol: data yang masuk sesuai aturan tipe

Kode lebih mudah dipahami: tipe terlihat jelas

Mencegah bug: tidak bisa sembarang memasukkan data

Struktur program lebih rapi: penggunaan generic jadi terarah

🌸 Pembatasan Tipe pada Interface dan Class

Pembatasan tipe pada generic (extends) digunakan untuk membatasi tipe data yang boleh dipakai, sehingga hanya tipe tertentu (misalnya Iterable) yang bisa digunakan dan mencegah kesalahan program.

Sukses

Karena List dan Set termasuk Iterable, sesuai dengan batasan extends Iterable.

//Nim   : 251410011
//Kelas : SI2A

void tampilkan<T extends Iterable>(T data) {

    print(item);

  tampilkan<Set<String>>({'A', 'B', 'C'});
}

Praktik 1 - Generic Class dan fungsi

1. Buat class Repository <T> dengan:

Method: save(T item) , T getById(int id) , List <T> getAll()

2. Buat fungsi generic swap<T>(List<T> list, int i, int j)

3. Buat class Triple<A, B, C> dengan 3 field


// Nama   : Alicia Putri Lestari
// Nim    : 251410011
// Kelas  : SI2A

class Repository<T> {
  final List<T> _data = [];

  void save(T item) {
    _data.add(item);
  }

  T getById(int id) {
    return _data[id];
  }

  List<T> getAll() {
    return _data;
  }
}

// Fungsi swap
void swap<T>(List<T> list, int i, int j) {
  T temp = list[i];
  list[i] = list[j];
  list[j] = temp;
}

// Class Triple
class Triple<A, B, C> {
  A first;
  B second;
  C third;

  Triple(this.first, this.second, this.third);
}

void main() {
  // ===== Repository =====
  var repo = Repository<String>();
  repo.save("Data 1");
  repo.save("Data 2");

  print(repo.getById(0)); // Data 1
  print(repo.getAll());   // [Data 1, Data 2]

  // ===== Swap =====
  var list = [1, 2, 3];
  swap(list, 0, 2);
  print(list); // [3, 2, 1]

  // ===== Triple =====
  var triple = Triple<String, int, double>("Nilai", 100, 3.14);
  print('${triple.first}, ${triple.second}, ${triple.third}');
}

🌸 Generic vs dynamic vs Object

AspekGeneric <T>dynamicObject
Type Safety✅ Compile-time❌ Runtime⚠️ Perlu casting
FleksibilitasTerbatas sesuai TSangat fleksibelTerbatas
Performa✅ OptimalAda overhead✅ Optimal
CastingTidak perluTidak perluPerlu eksplisit
 

class Box<T> {
  T value;
  Box(this.value);
}

void main() {
  // ======================
  // Generic (aman)
  // ======================
  Box<int> box1 = Box<int>(42);
  print("Generic: ${box1.value}"); // Output: 42

  // ======================
  // Dynamic (fleksibel)
  // ======================
  dynamic box2 = 42;
  print("Dynamic: $box2"); // Output: 42

  // ======================
  // Object (perlu casting)
  // ======================
  Object box3 = 42;

  // casting aman
  if (box3 is int) {
    int angka = box3;
    print("Object: $angka"); // Output: 42
  }
}

🌸 Studi kasus - Cache Generic

Cache Generic adalah penyimpanan sementara (cache) yang menggunakan generic <T> sehingga bisa menyimpan berbagai tipe data (seperti String, int, atau objek) dengan aman dan fleksibel.


// Nama : Alicia Putri Lestari
// Nim  : 251410011
// Kelas: SI2A

class Cache<T> {
  final Map<String, T> _storage = {};

  void set(String key, T value) {
    _storage[key] = value;
  }

  T? get(String key) {
    return _storage[key];
  }

  void remove(String key) {
    _storage.remove(key);
  }
}

// Tambahan class Product (biar tidak error)
class Product {
  String name;
  int price;

  Product(this.name, this.price);

  @override
  String toString() {
    return "$name - $price";
  }
}

void main() {
  // ======================
  // Cache String
  // ======================
  var userCache = Cache<String>();
  userCache.set('name', 'Alice');

  print(userCache.get('name')); // Output: Alice

  // ======================
  // Cache Object (Product)
  // ======================
  var productCache = Cache<Product>();
  productCache.set('p1', Product('Laptop', 1000));

  print(productCache.get('p1')); // Output: Laptop - 1000
}

🌸 Latihan

Latihan ini melatih cara memakai generic (T) supaya kode bisa dipakai untuk berbagai tipe data tanpa harus bikin ulang.


// Nama : Alicia Putri Lestari
// Nim  : 251410011
// Kelas: SI2A

class Stack<T> {
  List<T> _data = [];

  void push(T value) {
    _data.add(value);
  }

  T? pop() {
    if (_data.isEmpty) return null;
    return _data.removeLast();
  }

  T? peek() {
    if (_data.isEmpty) return null;
    return _data.last;
  }
}

void main() {
  var stack = Stack<int>();

  stack.push(10);
  stack.push(20);
  stack.push(30);

  print(stack.peek()); // Output: 30
  print(stack.pop());  // Output: 30
  print(stack.pop());  // Output: 20
  print(stack.peek()); // Output: 10
}

🌸 Kesimpulan & Poin Penting

  • Generic menjaga keamanan tipe data tanpa mengurangi fleksibilitas kode.
  • Dapat menggunakan satu tipe (<T>) atau lebih (<K, V>).
  • Penggunaan extends untuk membatasi tipe tertentu.
  • Lebih aman dibanding dynamic atau Object karena dicek saat compile.
  • Contoh penerapan: List<T>, Map<K, V>, dan struktur generic lainnya.
