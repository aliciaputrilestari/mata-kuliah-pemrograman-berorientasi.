Soal 2: Extension Method & Private Member

Extension method tidak bisa mengakses _value langsung karena private. Solusinya: gunakan method public getValue() sebagai jembatan.

// Nama  : Alicia Putri LESTARI
// Nim   : 251410011
// Kelas : SI2A

class Counter {
  int _value = 0; // private di Dart pakai underscore

  void increment() {
    _value++;
  }

  int getValue() {
    return _value;
  }
}

// Syntax extension di Dart
extension CounterStats on Counter {
  String getStats() {
    return 'Current value: ${this.getValue()}';
  }
}

void main() {
  var c = Counter();
  c.increment();
  print(c.getValue());   // Output: 1
  print(c.getStats());   // Output: Current value: 1
}

Soal 3: Prioritas Method Asli vs Extension (dan Nullable)

- Output program: *"Hello from class"* — method asli selalu menang atas extension method dengan nama sama

- Jika obj bernilai null: extension method *bisa* dipanggil pada nullable receiver (Greeting?), sedangkan method asli tidak bisa (akan throw NullPointerException). Solusi: gunakan nullable receiver di extension seperti fun Greeting?.safeCall() 

// Nama  : Alicia Putri LESTARI
// Nim   : 251410011
// Kelas : SI2A

class Greeting {
  String say() => 'Hello from class';
}

extension GreetingExt on Greeting {
  String sayExt() => 'Hello from extension';
}

// Extension untuk nullable
extension NullableGreeting on Greeting? {
  String safeCall() {
    return this?.say() ?? 'Object is null!';
  }
}

void main() {
  Greeting? obj = Greeting();
  print(obj?.say());      // Output: Hello from class

  Greeting? nullObj = null;
  print(nullObj.safeCall()); // Output: Object is null!
}
