MAIN CONSTRUCTOR DENGAN RADIUS

Main Constructor adalah constructor utama yang digunakan untuk membuat objek dengan menerima nilai radius (jari-jari) secara langsung.

// Nama  : Alicia Putri Lestari
// Nim   : 251410011
// Kelas : SI2A

class Circle {
  // Konstruktor Utama: Langsung pakai Radius
  final double radius;
  static const double pi = 3.14159;

  Circle(this.radius);

  void info() {
    print('=== DIBUAT DARI RADIUS ===');
    print('Jari-jari : ${radius.toStringAsFixed(2)}');
    print('Diameter  : ${(2 * radius).toStringAsFixed(2)}');
    print('Keliling : ${(2 * pi * radius).toStringAsFixed(2)}');
    print('Luas     : ${(pi * radius * radius).toStringAsFixed(2)}');
    print('---------------------------');
  }
}

void main() {
  // Membuat lingkaran langsung pakai nilai radius
  var lingkaran = Circle(10);
  lingkaran.info();
}

REDIRECTING DARI DIAMETER

Redirecting Constructor dari diameter digunakan ketika yang diketahui adalah diameter, tetapi class membutuhkan radius.

// Nama  : Alicia Putri Lestari
// Nim   : 251410011
// Kelas : SI2A

class Circle {
  final double radius;
  static const double pi = 3.14159;

  // Konstruktor Utama
  Circle(this.radius);

  // Konstruktor Redirecting: Dari Diameter -> ke Radius
  Circle.fromDiameter(double diameter) : this(diameter / 2);

  void info() {
    print('=== DIBUAT DARI DIAMETER ===');
    print('Jari-jari : ${radius.toStringAsFixed(2)}');
    print('Diameter  : ${(2 * radius).toStringAsFixed(2)}');
    print('Keliling : ${(2 * pi * radius).toStringAsFixed(2)}');
    print('Luas     : ${(pi * radius * radius).toStringAsFixed(2)}');
    print('---------------------------');
  }
}

void main() {
  // Membuat lingkaran pakai nilai diameter
  var lingkaran = Circle.fromDiameter(20);
  lingkaran.info();
}

IMPLEMENTASI LENGKAP REDIRECTING CONSTRUCTOR PADA CLASS CIRCLE

// Nama : Alicia Putri Lestari
// Nim  : 251410011
// Kelas: SI2A

import 'dart:math';

class Circle {
  final double radius;
  static const double pi = 3.14159;

  // Konstruktor Utama
  Circle(this.radius);

  // Redirecting Constructor (Sesuai Materi)
  Circle.fromDiameter(double diameter) : this(diameter / 2);
  Circle.fromKeliling(double keliling) : this(keliling / (2 * pi));
  
  // ✅ PERBAIKAN: Ubah dari (nilai).sqrt() jadi sqrt(nilai)
  Circle.fromLuas(double luas) : this( sqrt(luas / pi) );

  void info() {
    print('Jari-jari : ${radius.toStringAsFixed(2)}');
    print('Diameter  : ${(2 * radius).toStringAsFixed(2)}');
    print('Keliling  : ${(2 * pi * radius).toStringAsFixed(2)}');
    print('Luas      : ${(pi * radius * radius).toStringAsFixed(2)}');
    print('----------------------------------------');
  }
}

void main() {
  print('=== UJI COBA SEMUA KONSTRUKTOR ===');
  
  print('> Dibuat dari Radius (10):');
  Circle(10).info();

  print('> Dibuat dari Diameter (20):');
  Circle.fromDiameter(20).info();

  print('> Dibuat dari Keliling (31.4159):');
  Circle.fromKeliling(31.4159).info();

  print('> Dibuat dari Luas (78.53975):');
  Circle.fromLuas(78.53975).info();
}

KESIMPULAN

- Redirecting Constructor berfungsi memanggil konstruktor lain dalam kelas yang sama lewat sintaks  : this(...) .

- Mencegah penulisan kode berulang saat menyiapkan data awal objek.

- Tanpa isi badan  { } , tugasnya hanya meneruskan nilai ke konstruktor utama.

- Memudahkan pembuatan objek dengan berbagai cara atau sumber nilai masukan.

- Kode jadi lebih pendek, rapi, terstruktur, dan mudah diperbaiki/dikembangkan.

- Menerapkan prinsip DRY, mengurangi penyalinan kode agar lebih efisien.
