Builder Pattern

Builder Pattern adalah design pattern yang memisahkan proses konstruksi objek kompleks dari representasinya. Tujuannya agar kamu bisa membuat objek dengan banyak parameter secara bertahap dan terbaca (fluent API).

// Nama  : Alicia Putri Lestari
// Nim   : 251410011
// Kelas : SI2A

class Pizza {
  final String size;
  final List toppings;

  Pizza({required this.size, required this.toppings});

  @override
  String toString() => 'Pizza { size: $size, toppings: $toppings }';
}

class PizzaBuilder {
  String _size = 'medium';
  final List _toppings = [];

  PizzaBuilder size(String s) {
    _size = s;
    return this;
  }

  PizzaBuilder addTopping(String t) {
    _toppings.add(t);
    return this;
  }

  Pizza build() => Pizza(size: _size, toppings: _toppings);
}

void main() {
  Pizza p = PizzaBuilder()
      .size('large')
      .addTopping('cheese')
      .addTopping('mushroom')
      .build();

  print(p);
}

Pengantar Extension Methods

Builder Pattern adalah design pattern yang memisahkan proses konstruksi objek kompleks dari representasinya. Tujuannya agar kamu bisa membuat objek dengan banyak parameter secara bertahap dan terbaca (fluent API).

Masalah Tanpa Extension Methods

Slide ini menunjukkan *cara lama* sebelum ada Extension Methods. Programmer biasanya membuat *Utility Class* yaitu class khusus yang isinya kumpulan fungsi static untuk membantu pengolahan data.

 

Masalahnya:

- Cara penulisannya tidak natural → StringUtils.capitalize(name) — objeknya jadi parameter, bukan subjek

- Harus hafal nama class utility-nya

- Makin banyak fungsi, makin banyak utility class yang harus diingat

- Kode terasa seperti memanggil fungsi biasa, bukan method dari objeknya sendiri

// Nama  : Alicia Putri Lestari
// Nim   : 251410011
// Kelas : SI2A

// Utility class yang kurang natural
class StringUtils {
  static String capitalize(String text) {
    if (text.isEmpty) return text;
    return text[0].toUpperCase() + text.substring(1);
  }

  static bool isEmail(String text) {
    return text.contains('@');
  }
}

void main() {
  var name = 'john';

  // Penggunaan kurang natural
  var capitalized = StringUtils.capitalize(name);
  var isEmail = StringUtils.isEmail('test@mail.com');

  print('Original name: $name');
  print('Capitalized name: $capitalized');
  print('Is "test@mail.com" an email? $isEmail');
}

Solusi dengan Extension Methods

Slide ini menunjukkan *cara baru* menggunakan Extension Methods. Alih-alih buat utility class terpisah, kita "tempelkan" method langsung ke tipe String menggunakan keyword extension.

 

Keunggulannya:

capitalize() → method biasa, dipanggil dengan name.capitalize() — lebih intuitif karena subjeknya adalah objeknya sendiri

isEmail → pakai get karena tidak butuh parameter, cukup akses seperti properti → 'test@mail.com'.isEmail

reverse() → method biasa yang membalik urutan karakter string

// Nama  : Alicia Putri Lestari
// Nim   : 251410011
// Kelas : SI2A

 // Extension method untuk String
extension StringExtensions on String {
  
  String capitalize() {
    if (isEmpty) return this;
    return this[0].toUpperCase() + substring(1);
  }

  bool get isEmail => contains('@');

  String reverse() {
    return split('').reversed.join();
  }
}

void main() {
  var name = 'john';

  // Penggunaan lebih natural
  var capitalized = name.capitalize();
  var isEmail = 'test@mail.com'.isEmail;
  var reversed = 'hello'.reverse();

  print('Original name: $name');
  print('Capitalized name: $capitalized');
  print('Is "test@mail.com" an email? $isEmail');
  print('Reversed "hello": $reversed');
}

Sintaks Extension Methods

Extension bisa berisi 3 hal: *Method, **Getter, dan **Operator*. Contohnya diterapkan ke tipe DateTime.

 

Method → fungsi biasa yang dipanggil dengan ()

Getter → akses seperti properti, tanpa ()

Operator → mendefinisikan ulang simbol seperti +

// Nama  : Alicia Putri Lestari
// Nim   : 251410011
// Kelas : SI2A

extension DateTimeExtensions on DateTime {
  
  // Method: format tanggal jadi string
  String toFormattedString() {
    return '$day/$month/$year';
  }

  // Getter: cek apakah tanggal ini hari ini
  bool get isToday {
    var now = DateTime.now();
    return year == now.year &&
           month == now.month &&
           day == now.day;
  }

  // Operator: tambah durasi ke DateTime
  DateTime operator +(Duration duration) {
    return add(duration);
  }
}

void main() {
  var today = DateTime.now();
  var ultah = DateTime(2000, 8, 17);

  print(today.toFormattedString());   // misal: 19/5/2026
  print(today.isToday);              // true
  print(ultah.isToday);             // false

  var besok = today + Duration(days: 1);
  print(besok.toFormattedString());  // besok
}

Tipe yang Bisa Di-extend

Extension tidak hanya untuk String. Hampir *semua tipe di Dart bisa di-extend*, yaitu:

 

Built-in types → String, int, double, List, Map, dll

Custom classes* → class buatan sendiri

Generic types* → List, Map

Nullable types* → String?, int?

// Nama  : Alicia Putri Lestari
// Nim   : 251410011
// Kelas : SI2A

// Extension untuk List
extension IntListExtensions on List {
  
  // Jumlah semua elemen
  int get sum => fold(0, (total, item) => total + item);

  // Rata-rata semua elemen
  double get average => isEmpty ? 0 : sum / length;
}

void main() {
  var numbers = [1, 2, 3, 4, 5];

  print(numbers.sum);      // 15
  print(numbers.average);  // 3.0
}

Extension untuk Null Safety

Extension bisa diterapkan ke tipe *nullable* (String?). Berguna untuk menghindari error saat nilai bisa null.

 

- ?? = operator "jika null, pakai nilai ini"

- this = merujuk ke objek yang memanggil method

// Nama  : Alicia Putri Lestari
// Nim   : 251410011
// Kelas : SI2A

extension NullableStringExtensions on String? {
  
  // Jika null, kembalikan string kosong
  String orEmpty() => this ?? '';

  // Cek apakah null atau kosong
  bool get isNullOrEmpty => this == null || this!.isEmpty;

  // Kebalikannya
  bool get isNotNullOrEmpty => !isNullOrEmpty;

  // Jika null, pakai nilai default
  String withDefault(String defaultValue) => this ?? defaultValue;
}

void main() {
  String? name; // null

  print(name.orEmpty());           // ''
  print(name.isNullOrEmpty);       // true
  print(name.isNotNullOrEmpty);    // false
  print(name.withDefault('Guest')); // Guest
}

Praktik 1: Utilities untuk Dart Types

Extension pada tipe num (mencakup int dan double) untuk keperluan sehari-hari: format rupiah, cek range, dan pangkat.

// Nama  : Alicia Putri Lestari
// Nim   : 251410011
// Kelas : SI2A

extension NumberExtensions on num {

  // Format angka ke Rupiah
  String toRupiah() {
    return 'Rp${toStringAsFixed(0).replaceAllMapped(
      RegExp(r'(\d{1,3})(?=(\d{3})+(?!\d))'),
      (match) => '${match[1]}.',
    )}';
  }

  // Cek apakah angka dalam range min-max
  bool isBetween(num min, num max) {
    return this >= min && this <= max;
  }

  // Pangkat sederhana
  num power(int exponent) {
    var result = this;
    for (var i = 1; i < exponent; i++) {
      result *= this;
    }
    return result;
  }
}

void main() {
  var price = 1500000;

  print(price.toRupiah());       // Rp1.500.000
  print(5.isBetween(1, 10));     // true
  print(2.power(3));             // 8
}

Generic Extensions

Extension pada List artinya berlaku untuk list bertipe apapun — List, List, dll. Huruf T adalah placeholder tipe.

 

- getOrNull → ambil elemen aman, tidak crash jika index salah

- chunk → pecah list jadi beberapa bagian kecil

- distinct → hapus duplikat dari list

// Nama  : Alicia Putri Lestari
// Nim   : 251410011
// Kelas : SI2A

extension ListExtensions on List {

  // Ambil elemen, null jika index di luar batas
  T? getOrNull(int index) {
    if (index < 0 || index >= length) return null;
    return this[index];
  }

  // Pecah list menjadi potongan-potongan kecil
  List> chunk(int size) {
    var chunks = >[];
    for (var i = 0; i < length; i += size) {
      chunks.add(sublist(i, i + size > length ? length : i + size));
    }
    return chunks;
  }

  // Hapus elemen duplikat
  List distinct() {
    var result = [];
    for (var item in this) {
      if (!result.contains(item)) {
        result.add(item);
      }
    }
    return result;
  }
}

void main() {
  var numbers = [1, 2, 3, 4, 5, 6, 7];

  print(numbers.getOrNull(2));              // 3
  print(numbers.getOrNull(99));             // null
  print(numbers.chunk(3));                  // [[1,2,3],[4,5,6],[7]]
  print([1, 2, 2, 3, 3, 3].distinct());    // [1, 2, 3]
}

Unnamed Extensions

Extension tanpa nama — hanya bisa dipakai di file yang sama. Tidak bisa diimport ke file lain. Cocok untuk helper internal yang tidak perlu dibagikan.

// Nama  : Alicia Putri Lestari
// Nim   : 251410011
// Kelas : SI2A

extension on DateTime {
  // Format tanggal ke YYYY-MM-DD
  String get toYYYYMMDD {
    return '$year-${month.toString().padLeft(2, '0')}-${day.toString().padLeft(2, '0')}';
  }

  // Awal hari (jam 00:00:00)
  DateTime get startOfDay {
    return DateTime(year, month, day);
  }
}

void main() {
  var today = DateTime.now();

  print(today.toYYYYMMDD);   // misal: 2026-05-19
  print(today.startOfDay);   // 2026-05-19 00:00:00.000
}

Konflik Nama Extension

Jika dua extension punya method dengan nama sama pada tipe yang sama, Dart akan error karena tidak tahu mau pakai yang mana. Solusinya pakai as (prefix) atau hide.

// Nama  : Alicia Putri Lestari
// Nim   : 251410011
// Kelas : SI2A

// Extension 1
extension StringCaseExtensions on String {
  String capitalize() {
    if (isEmpty) return this;
    return this[0].toUpperCase() + substring(1);
  }
}

// Extension 2 — nama method sama tapi logika berbeda
extension TextUtilsExtensions on String {
  String capitalize() {
    return toUpperCase(); // versi berbeda
  }
}

void main() {
  var text = 'hello';

  // Jika dua extension aktif bersamaan → ERROR ambiguous
  // Solusi: panggil langsung pakai nama extension
  print(StringCaseExtensions(text).capitalize()); // Hello
  print(TextUtilsExtensions(text).capitalize());  // HELLO
}

Extension untuk Custom Classes

Extension tidak hanya untuk tipe bawaan Dart — bisa juga untuk class buatan sendiri. Berguna untuk menambah fitur ke class tanpa mengubah kode class aslinya.

// Nama  : Alicia Putri Lestari
// Nim   : 251410011
// Kelas : SI2A

// Class asli — tidak diubah sama sekali
class Product {
  final String name;
  final double price;
  Product(this.name, this.price);
}

// Extension untuk double → format Rupiah
extension DoubleRupiahFormatter on double {
  String toRupiah() {
    final intValue = toInt();
    String numberString = intValue.toString();
    String formattedString = '';
    int counter = 0;

    for (int i = numberString.length - 1; i >= 0; i--) {
      formattedString = numberString[i] + formattedString;
      counter++;
      if (counter % 3 == 0 && i != 0) {
        formattedString = '.' + formattedString;
      }
    }
    return 'Rp$formattedString';
  }
}

// Extension untuk Product
extension ProductExtensions on Product {
  
  // Hitung harga setelah diskon
  Product withDiscount(double percentage) {
    var discountedPrice = price * (1 - percentage / 100);
    return Product(name, discountedPrice);
  }

  // Info singkat untuk ditampilkan
  String get displayInfo => '$name - ${price.toRupiah()}';

  // Cek apakah harga di atas 1 juta
  bool get isExpensive => price > 1000000;
}

void main() {
  var laptop = Product('Laptop', 15000000);
  var discounted = laptop.withDiscount(10);

  print(discounted.displayInfo);  // Laptop - Rp13.500.000
  print(laptop.isExpensive);      // true

  var keyboard = Product('Keyboard', 750000);
  print(keyboard.displayInfo);    // Keyboard - Rp750.000
  print(keyboard.isExpensive);    // false
}

Praktik 2: Validator Extensions

Extension yang berisi kumpulan validator — mengecek apakah suatu nilai memenuhi syarat tertentu. Sangat berguna untuk validasi form di aplikasi.:

// Nama  : Alicia Putri Lestari
// Nim   : 251410011
// Kelas : SI2A

// Validator untuk String
extension StringValidators on String {
  
  // Cek format email
  bool get isEmail {
    return RegExp(r'^[\w-\.]+@([\w-]+\.)+[\w-]{2,4}$').hasMatch(this);
  }

  // Cek nomor HP (10-13 digit)
  bool get isPhoneNumber {
    return RegExp(r'^[0-9]{10,13}$').hasMatch(this);
  }

  // Cek password kuat: min 8 karakter, ada huruf besar, kecil, angka
  bool get isStrongPassword {
    return length >= 8 &&
        contains(RegExp(r'[A-Z]')) &&
        contains(RegExp(r'[a-z]')) &&
        contains(RegExp(r'[0-9]'));
  }

  // Cek apakah valid URL
  bool get isUrl {
    try {
      Uri.parse(this);
      return true;
    } catch (_) {
      return false;
    }
  }
}

// Validator untuk int
extension IntValidators on int {
  bool get isAdultAge   => this >= 18;
  bool get isPositive   => this > 0;
  bool get isEven       => this % 2 == 0;
  bool get isOdd        => this % 2 != 0;
}

void main() {
  var email    = 'test@example.com';
  var age      = 25;
  var password = 'Pass1234';

  print(email.isEmail);             // true
  print(age.isAdultAge);            // true
  print(password.isStrongPassword); // true
  print(16.isEven);                 // true
  print(7.isOdd);                   // true
  print('081234567890'.isPhoneNumber); // true
}

Ringkasan & Best Practices

Ringkasan

1. Extension Methods → cara menambah method baru ke tipe yang sudah ada tanpa ubah kode aslinya

2. Sintaks → selalu mengikuti pola extension NamaExtension on TipeTarget

3. Support → di dalam extension bisa berisi method, getter, setter, dan operator

4. Generic → bisa diterapkan ke tipe generik seperti List agar berlaku untuk semua tipe list

 

Best Practices

1. Nama jelas → beri nama extension yang deskriptif seperti StringExtensions atau DateTimeUtils agar mudah dikenali

2. Group by type → kelompokkan extension berdasarkan tipe targetnya, satu file per tipe. Contoh: semua extension untuk String di satu file

3. Avoid overuse → tidak semua fungsi perlu dijadikan extension. Kalau fungsinya tida…
